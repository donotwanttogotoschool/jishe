中国古代自然科学知识库
项目概述
中国古代自然科学知识库是一个集成了中国古代科学成就、历史人物和科技著作的可视化平台。通过丰富的图表、地图和互动元素，直观展示中国古代在天文、医学、农业、数学、工程等领域的科技发展历程，为研究者和爱好者提供一站式的知识探索体验。

技术架构
1.后端：Flask (Python)
2.前端：HTML, CSS, JavaScript
3.数据可视化：ECharts
4.地图服务：高德地图 API
5.数据处理：Pandas, CSV

安装步骤
1.环境要求
a.Python 3.7+
b.pip (Python包管理器)
2.安装依赖
pip install -r requirements.txt
3.运行项目
python app.py

主要功能
1.成就展示：展示中国古代重要科技成就，包括指南针、活字印刷、火药、造纸术等
2.人物图鉴：展示中国古代科学家及其贡献
3.著作档案：整理中国古代重要科学著作，如《本草纲目》、《天工开物》、《梦溪笔谈》等
4.地域分布：通过高德地图展示各地区科技发展情况
5.时间分析：按朝代展示科技发展历程
6.领域分析：按学科领域统计科技成就
7.数据可视化：通过多种图表直观展示统计数据
8.交互式探索：用户可通过点击、筛选等方式探索数据
9.专题探索：Norstar模块提供深入的主题研究和AI辅助探索功能
10.地区科技：shengfen模块展示各省份特色科技成就和历史贡献
11.文明解码：Terris模块通过多媒体方式解读科技对文明发展的影响

模块说明
1.主平台：以app.py为入口的Flask应用，提供基础数据展示和交互
2.Norstar模块：专题探索系统，提供特定主题的深入研究，包含:
  - 灵枢AI：智能对话系统，帮助用户探索科技历史
  - 发明专题：聚焦重要发明的详细解析
  - 人物专题：重点介绍重要科学家的生平和贡献
3.shengfen模块：各省份科技成就展示系统，按地域分类展示科技发展史
  - 提供交互式地图，展示各省历史上的科技发展脉络
  - 汇总各地区代表性人物、成就和著作
4.Terris模块：文明解码系统，从文明演进角度分析科技发展
  - 提供多媒体展示，包括图片、视频资源
  - 通过作品集展示科技对文明进程的影响

数据结构
数据主要以CSV格式存储，包括：
{领域}_人物_clean.csv：各领域历史人物数据
{领域}_成就_clean.csv：各领域科技成就数据
{领域}_著作_clean.csv：各领域科学著作数据

注意事项
1.地图功能需要有效的高德地图API Key和稳定的网络连接
2.部署到生产环境时，应使用专业的Web服务器如Gunicorn或uWSGI
3.默认使用的审图号(GS(2023)3377号 - 甲测资字1100471)仅用于示例，实际使用需获取合法审图号
4.本地开发时，若CDN资源无法加载，可下载相应资源到本地static目录
5.shengfen模块需要完整的echarts-map-master资源文件才能正确显示地图
